## [Scientific Figure Workbench](https://github.com/yuanzhifang30-sudo/scientific-figure-workbench)

**科研图件验收工作台 · 任务分配、版本复核、人工验收与固定图包**

- 图件看板、每人两张在途限制、历史版本与图像对照。
- PNG/CSV与文件哈希检查；人工决定绑定具体提交版本。
- 全部当前版本通过后冻结ZIP、版本清单与文件哈希。
- 本地可运行原型、匿名自造图件、Agent辅助复核Skill及自动化测试。

## [Research Evidence Kit](https://github.com/yuanzhifang30-sudo/research-evidence-kit)

**科研实验与结果核验工具 · Python CLI + Agent Skill**

核对实验覆盖、输入与配置身份、版本和证据文件哈希；分别计算两种比较口径，保留缺测、失败、超时和退化案例。

- JSON、Markdown与单文件交互式HTML报告。
- 配套Agent Skill、匿名自造示例和Windows/Linux自动验证。
